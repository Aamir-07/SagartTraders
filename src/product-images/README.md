# Product image folders

Add the categorized product-image ZIP contents to the matching folders below. Supported formats: `.jpg`, `.jpeg`, `.png`, and `.webp`. Keep one category per folder; the catalog automatically lists image files and derives their display names from filenames on the next build.

- `mica/`
- `plywood/`
- `hardware-accessories/`
- `doors/`
- `adhesives-essentials/`
- `furniture-hardware/`
- `furniture/`

Keep filenames descriptive, for example `walnut-texture.jpg` or `concealed-hinge.png`. The site does not create prices, stock claims, or product guarantees from photos.
